# yousef-vcf

VCF contact card for Youssef Elmrabit, served via GitHub Pages.

## Links

- **Landing page:** https://moefingers.github.io/yousef-vcf/
- **Direct download (zero-click):** https://moefingers.github.io/yousef-vcf/vcard/

## Structure

```
public/
  index.html                    Landing page
  vcard/
    Youssef_Elmrabit.vcf        The contact card
    index.html                  Auto-redirect for direct download
```

## Deployment

Deployed automatically via GitHub Actions on push to `main` or `shepherd`. Source is set to **GitHub Actions** in repo Settings > Pages.
